### 1. Login vào server bằng user oracle sau đó vào đường dẫn oracle home, export DISPLAY nếu cần thiết

```bash
su - oracle
cd
. .bash_profile
cd /u01/app/oracle/product/19.0.0/dbhome_1/

./runInstaller
```

### 2. Khi Installer windows mở ra, chọn như bên dưới:
