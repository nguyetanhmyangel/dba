# Sau khi cài xong chạy thử kiểm tra:
- 1. User oracle:

```bash
su - oracle
export ORACLE_SID=orclcdb
sqlplus / as sysdba
```
- Check Instance:
```bash
select instance_name,status from v$instance;
# output mong đợi status phải là OPEN
```
- Check database:

```bash
select name,open_mode from v$database;
```
Output mong đợi:

# NAME      OPEN_MODE
# --------- --------------------
# ORCLCDB   READ WRITE

- Check listener:

```bash
lsnrctl status
```
	Output mong đợi:

	- Listener khởi động thành công (không có lỗi TNS-12541: TNS:no listener).
	- Hiển thị:
		- STATUS of the LISTENER
		- Alias LISTENER
		- Version TNSLSNR for Linux: Version 19.x.x.x.x
	- Có thông tin thời gian hoạt động:
		- Start Date
		- Uptime
	- Có mục Listening Endpoints Summary.
	- Listener đang lắng nghe trên cổng 1521, ví dụ: (PROTOCOL=tcp)(HOST=<hostname>)(PORT=1521)
	- Có mục Services Summary.
	- Database đã đăng ký với Listener, ví dụ: Service "orclcdb" has 1 instance(s) hoặc Service "ORCLCDB" has 1 instance(s).
	- Instance có trạng thái: status READY
	- Hiển thị thêm các service của PDB(Nếu có PDB), ví dụ: orclpdb, orclpdb1
	- Kết thúc bằng thông báo: The command completed successfully


- 2. Với user grid:

```bash
su - grid
srvctl status database -d orclcdb 
# output mong đợi trả về Database is running.
crsctl stat res -t
# output mong đợi trả về Target là ONLINE
sqlplus / as sysasm
select instance_name,status from v$instance;
# output mong đợi status là STARTED, ASM không có trạng thái OPEN.
```

- 3. Troubleshooting - Grid Infrastructure Issues

- Grid Won't Start
```bash
crsctl check crs
ls -la $ORACLE_HOME/log/
sudo /u01/app/grid/bin/crsctl stop crs
sudo /u01/app/grid/bin/crsctl start crs
```
- ASM Not Found
```bash
ls -la $ORACLE_HOME/asm/
srvctl start asm
```
- Permission Denied
```bash
ls -ld /u01/app/grid
sudo chown -R oracle:oinstall /u01/app/grid
sudo chmod -R 755 /u01/app/grid
```
- Database Won't Start
```bash
sqlplus / as sysdba
SQL> startup
tail -100 $ORACLE_BASE/diag/rdbms/PROD/PROD/trace/alert_orclcdb.log
```
- Listener Issues
```bash
lsnrctl status
lsnrctl stop
lsnrctl start
cat $ORACLE_HOME/network/admin/listener.ora
```
- Can't Connect
```bash
tnsping orclcdb
cat $ORACLE_HOME/network/admin/tnsnames.ora
```bash
